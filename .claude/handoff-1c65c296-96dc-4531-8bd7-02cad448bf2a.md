I removed the payload read outright instead of demoting it to a fallback the way I had in the other two hooks; `test-auto-compact.sh` (8) and `test-hook-fork-budget.sh` (1) pin that contract. - **Second red suite: the new test file had no trailing `report` call.** Every file in `tests/` ends with it; it prints the per-file summary and sets the exit code. Without it the file exits on whatever ran last and `run.sh` counts it as failing. Harness convention, not a product bug.
