### Decisions Made
- `onFailure:block` only on the 4 core guards first: the replay proved those 4; the other ~56 PreToolUse hooks extend later, each after its own replay.
- Version-gated in the installer, not unconditional: an older Claude Code never saw the field. Unknown version = off.
- Overrun record stores a command hash, never the command: the command may hold a secret.
- Per-repo commit types via `git config`, not `.supercharger.json`: native per-repo, one git fork only on commit commands. Tokens outside `[a-z0-9-]` dropped so the value cannot reshape the regex.
- `disableAllHooks` added to the health check alongside `IS_DEMO`: same blind spot (canary green, Claude Code runs no hooks).
