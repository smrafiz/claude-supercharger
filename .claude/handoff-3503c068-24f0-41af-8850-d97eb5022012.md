### Decisions Made
- **Warn, don't block, on PostToolUse**: the command has already executed, so a blocking exit
  prevents nothing — it only escalated a heuristic into Stop-hook feedback that re-fired on
  the output of any attempt to investigate it. The file's own header already stated this
  contract ("Non-destructive ... this only WARNs the model"); `exit 2` contradicted it.
- **Match instructions, not vocabulary**: the bare-noun rule was the only one in the panel
  matching a word rather than a construction. A real payload must say what to *do*, which the
  instruction-shaped rules already catch — so it added ~no marginal detection while producing
  most of the false positives.
- **Scope the self-inspection exemption to the two scanner sources by name**, not the whole
  hooks dir: a poisoned payload can still arrive via `cat hooks/<anything-else>`, and those two
  files are the only ones whose content matching the panel is a tautology.
- **Dedup lib sourced lazily inside the emit block**, not at file top — the fast-path gate
  returns on the overwhelming majority of Bash calls and must not pay for a lib it never reaches.
- Monetization thread (no code): keep the core MIT as distribution; sell a **team tier** on the
  aggregated audit trail, not the guardrails. Rename before invoicing — "Claude Supercharger"
  puts Anthropic's trademark in a commercial product name. Sole copyright (one author, one
  email), deps are BSD-3 + 5× MIT, all permissive. MIT on shipped versions is irrevocable.
