## Decisions Made

- **`bash -c` blanket deny KEPT.** Measured load-bearing: neutralise
  `hooks/safety.sh:575` and `bash -c 'rm -rf /'` goes deny → allow, because the
  segment splitter cannot see inside the quoted payload. Its 9 false positives in
  20,722 commands (0.04%) are the correct price. **Do not "fix" this.**
- **Existence, not checksums, for hook integrity.** A manifest is a second file
  that drifts, needs regenerating per release, and can itself be stripped — the
  hole closed in v4.0.10. Existence needs no manifest and catches the failure the
  project actually had (v2.17.3 shipped `safety-detect.py` missing).
- **ASK, never deny**, for both new guards. Editing a locked range and writing a
  key file are legitimate work; doing either unknowingly is the problem. Same tier
  logic as human-approval-gate's PR-merge category.
- **`write-secret-guard` in the base set, `ai-lock-guard` in full.** The first has
  its three sibling channels in the base set and parity is its whole argument; the
  second is opt-in and advisory, so safe mode (the core safety floor) is wrong for
  it. The safe-mode COUNT test is what caught that — see Measurements.
- **Both new guards read `lib-secret-patterns.sh` / the shared normaliser rather
  than owning copies.** The defect being fixed was channel drift, and a private
  list recreates it.

## Measurements

  command (276-line python heredoc, body kept because python is an executor);
  `tr -s ' '` equivalent **0.03s**, byte-identical. End to end >60s → **0.59s**.
  Crossover on prefixes, clock noise ~25ms: 1KB 37/27ms, 2KB 196/27ms, 4KB
  1699/25ms, 6KB 5197/24ms. `split_segments` was NOT the cost: 269 segments, 0.30s.
- **Ledger substitute-then-slice: 5256.2ms vs 22.5ms**, identical output.

  project 20,722 / 225 (**1.1%**). The prior session's "26 of 111" was drawn from
  the first half. Of the 225, only ~15 were mention-not-action.

  **9 loosened, 0 tightened**, all nine English prose.

  96-way 2 (~0.6%); every capture `rc=0 cats=[] stderr=`.

## Dead ends

- **The watchdog-under-load hypothesis, measured on the detector alone** —
  0/96 silent at 48-way. Wrong layer; see What Failed.
- **`0x[a-fA-F0-9]{64}` as the checksum false positive.** It requires a `0x`
  prefix and never matched. The culprit was the Bitcoin WIF pattern, found by
  looping SECRET_PATTERNS one at a time (`scratchpad/whichpat.sh`).
- **Prefix-truncating a command to get a scaling curve** — cutting mid-heredoc
  changes the command's SHAPE, producing a non-monotonic curve (6KB slower than
  8KB). Discarded.
- **`gh run view --log-failed` for per-test Windows detail** — it returns the
  gate's SOURCE. The failure list is in the build artifact (`gh run download`).
